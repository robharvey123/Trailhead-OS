# Trailhead Holdings SEO Implementation

Drop-in code and a manual checklist to take www.trailheadholdings.uk from "no SEO" to fully optimised in a single afternoon of dev work plus a couple of hours of admin.

The site is Next.js (App Router) on Vercel and pages are server-rendered, so every fix below is config and metadata work, not a re-platform.

---

## What's in this folder

```
SEO-Implementation/
  README.md                          ← this file
  lib/seo.ts                         ← central config + metadata helper
  components/JsonLd.tsx              ← Organization, WebSite, BlogPosting schemas
  vercel.json                        ← cache headers + non-www redirect
  app/
    layout.tsx.snippet               ← root layout metadata + JSON-LD mounting
    robots.ts                        ← /robots.txt
    sitemap.ts                       ← /sitemap.xml
    opengraph-image.tsx              ← default 1200x630 OG image (auto-generated)
    llms.txt/route.ts                ← /llms.txt
    page.tsx.snippet                 ← homepage metadata
    bright-fire/page.tsx.snippet     ← BrightFire page metadata
    contact/page.tsx.snippet         ← contact page metadata
    blog/page.tsx.snippet            ← blog index metadata
    blog/[slug]/page.tsx.snippet     ← per-post metadata + JSON-LD
    blog/[slug]/opengraph-image.tsx  ← per-post OG image
```

`.snippet` files are not standalone, they are fragments to merge into your existing page files (so I do not blow away your component code). `.tsx` and `.ts` files without `.snippet` can be copied straight in.

Path alias `@/` is assumed (the standard create-next-app default). If your repo uses something else, adjust the imports.

## Step 1, copy the code in (15 mins)

Inside your Next.js repo:

1. Copy `lib/seo.ts` → `lib/seo.ts`
2. Copy `components/JsonLd.tsx` → `components/JsonLd.tsx`
3. Copy `app/robots.ts` → `app/robots.ts`
4. Copy `app/sitemap.ts` → `app/sitemap.ts`
5. Copy `app/llms.txt/route.ts` → `app/llms.txt/route.ts`
6. Copy `app/opengraph-image.tsx` → `app/opengraph-image.tsx`
7. Copy `app/blog/[slug]/opengraph-image.tsx` → `app/blog/[slug]/opengraph-image.tsx`
8. Copy `vercel.json` → repo root (merge with any existing one)

Then merge each `.snippet` into the matching existing file:
- `app/layout.tsx` → replace the `metadata` export with what's in `layout.tsx.snippet`, add the `OrganizationJsonLd` and `WebSiteJsonLd` imports and tags inside `<body>`
- `app/page.tsx` → add the `metadata` export at the top
- `app/bright-fire/page.tsx` → add the `metadata` export
- `app/contact/page.tsx` → add the `metadata` export
- `app/blog/page.tsx` → add the `metadata` export
- `app/blog/[slug]/page.tsx` → replace your existing `generateMetadata` with the version in the snippet, add the `BlogPostingJsonLd` tag inside the rendered article

The blog snippet has stubs (`getPost`, `getAllPosts`) commented out. Wire those to whatever you currently use to load posts (MDX, contentlayer, fs reads, headless CMS). The required post shape:

```ts
{ title, description, slug, publishedAt, updatedAt?, author?, ogImage?, tags? }
```

## Step 2, things only you can do

### a) Edit `lib/seo.ts` defaults
- Confirm the X / Twitter handle (or remove the line if you do not have one)
- Add your company LinkedIn page to `sameAs` if it exists
- Confirm the address (Brentwood, Essex, GB)

### b) Add static assets to `/public`
- `/public/logo.png`, square logo, ideally 512×512 PNG with transparent background. Used in JSON-LD.
- `/public/favicon.ico`, already there probably, just confirm
- `/public/apple-touch-icon.png`, 180×180

(The OG image is auto-generated by `app/opengraph-image.tsx`, no static file required. If you'd prefer a designed one, drop a 1200×630 PNG at `app/opengraph-image.png` and Next.js will use it instead.)

### c) Decide www vs non-www
The `vercel.json` redirects `trailheadholdings.uk → www.trailheadholdings.uk`. If you'd rather use the apex domain, flip the redirect direction and change `SITE_URL` in `lib/seo.ts`. Whichever you pick, set the same as primary in Vercel project settings (Project → Settings → Domains, click the three dots, "Set as Primary Domain").

### d) Create Search Console + Bing Webmaster properties
1. Google Search Console: https://search.google.com/search-console → Add property → Domain (use `trailheadholdings.uk`, covers both www and non-www) → verify via DNS TXT record at your registrar.
2. Bing Webmaster Tools: https://www.bing.com/webmasters → Add Site → use the `www` URL → import from GSC (fastest) or verify via meta tag.
3. In each, submit `https://www.trailheadholdings.uk/sitemap.xml`.

If you prefer meta-tag verification, uncomment the `verification` block in `app/layout.tsx.snippet` and paste the tokens.

### e) Deploy and smoke-test
After deploying:
1. Visit `https://www.trailheadholdings.uk/robots.txt`, should return rules plus sitemap line
2. Visit `https://www.trailheadholdings.uk/sitemap.xml`, should list 4 URLs (more once posts are wired)
3. Visit `https://www.trailheadholdings.uk/llms.txt`, should return the markdown
4. Run the homepage through https://search.google.com/test/rich-results, should detect Organization and WebSite schemas
5. Run a blog post through the same tool, should detect BlogPosting schema
6. Test social previews:
   - LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/
   - X Card Validator: https://cards-dev.twitter.com/validator (or post a test draft)
   - Facebook Debugger: https://developers.facebook.com/tools/debug/

## Step 3, content work (next 2 to 4 weeks)

Code alone will not rank you. The on-page metadata above just makes the site indexable and shareable. To actually attract traffic:

1. **Build out service pages.** Anchor links inside the homepage do not rank. Each of the four services (NGP/FMCG consulting, bespoke app development, MVP Cricket, BrightFire) should have its own `/services/<slug>` page with at least 800 words, a case study, an FAQ, and a CTA. Add each new page to `STATIC_ROUTES` in `app/sitemap.ts`.
2. **Commit to a posting cadence.** Two blog posts is a placeholder. Aim for one post per fortnight, clustered around three pillars: NGP market intelligence, FMCG go to market, building software for real businesses. Interlink aggressively.
3. **Internal links from the homepage.** When service pages exist, link from the homepage feature blocks straight to them, not to `/#services`.
4. **Backlinks.** Update LinkedIn profile, MVP Cricket footer, BrightFire footer, Companies House to link back. Get one or two guest posts in NGP trade press (ECigIntelligence, Tobacco Reporter, Convenience Store).

## Step 4, monitor

Two weeks after deploy:
- Search Console → Coverage: should show all 4 (and growing) pages indexed
- Search Console → Performance: impressions for "trailhead holdings" should appear within days, broader queries within weeks
- PageSpeed Insights: aim for 90+ on mobile. Vercel + Next.js should make this trivial unless you have a heavy hero image. Run https://pagespeed.web.dev/ against the homepage.
